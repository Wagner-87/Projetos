# 📺 Meus Canais do YouTube Favoritos

Projeto simples em HTML5 com meus 5 canais favoritos do YouTube.

## 🎯 Sobre o Projeto

Este foi meu primeiro projeto HTML onde pratiquei:
- Tags semânticas (`<figure>`, `<figcaption>`)
- Inserir imagens (pasta `images/`)
- Criar links para sites externos
- Estruturar uma página HTML completa

## 🎬 Canais que estão no projeto

| Canal | Descrição |
|-------|-----------|
| Manual do Mundo | Experimentos científicos e curiosidades |
| Oficina Garagem | Solda e serralheria |
| Letra Jota | Curiosidades e tecnologia |
| Olhar Digital | Notícias sobre tecnologia |
| Ei Nerd | Cultura geek e games |
