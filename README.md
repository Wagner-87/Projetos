# App Meu Combustível (.NET MAUI)

Aplicação desenvolvida para cálculo e comparação entre Álcool e Gasolina (regra dos 70%).

## 🚀 Funcionalidades
* Entrada de marca e modelo do veículo.
* Inserção dos preços do Etanol e da Gasolina.
* Cálculo automático com recomendação do combustível mais vantajoso.
* Navegação simplificada entre campos com tecla 'Próximo'.

## 🛠️ Tecnologias Utilizadas
* **Language:** C#
* **Framework:** .NET 8 (MAUI)
* **IDE:** Visual Studio 2026
