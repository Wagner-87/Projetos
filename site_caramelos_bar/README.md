# 🍺 Caramelo's Bar

## 📌 Sobre o Projeto

O **Caramelo's Bar** é um site institucional desenvolvido como projeto acadêmico para a disciplina de **Desenvolvimento de Sistemas** da ETEC.

O objetivo do projeto é apresentar um bar temático inspirado na cultura retrô, música clássica e no carismático vira-lata caramelo brasileiro, utilizando tecnologias fundamentais do desenvolvimento web.

O site possui design responsivo, navegação intuitiva, slideshow de imagens, seção de parceiros, perguntas frequentes e formulário de contato.
