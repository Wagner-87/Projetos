# Projeto - Atrativos Turísticos de Marília-SP

## Descrição

Este projeto foi desenvolvido para a disciplina de Desenvolvimento de Sistemas da ETEC.

Criar um site responsivo apresentando os principais atrativos turísticos da cidade de Marília-SP, com no mínimo 6 cards, utilizando framework W3.CSS e boas práticas de desenvolvimento web.

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- Framework W3.CSS
- Flexbox/Grid do W3.CSS
- Visual Studio Code

---

## Recursos Utilizados

- Estrutura semântica HTML
- Layout em colunas
- Cards responsivos
- Efeito hover nas imagens
- CSS externo
- Organização em pastas
- Imagens locais
- Responsividade

## Como Executar

1. Baixe ou clone o repositório
2. Certifique-se de que a pasta `imagens` está no mesmo diretório do `index.html`
3. Abra o arquivo **`index.html`** em qualquer navegador
